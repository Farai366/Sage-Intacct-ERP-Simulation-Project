# To-Be Process Description — Project Ignite

| Process Name | Future Steps | ERP Module | Improvements | Controls |
|---|---|---|---|---|
| Month-End Close | 1) Both entities close within single Intacct instance 2) Consolidation runs automatically via multi-entity structure 3) Eliminations post automatically per configured intercompany rules 4) Standard report package generated from Intacct dashboards | GL | Close reduced to target 5 business days; eliminates manual Excel workbook | System-enforced period close/lock; close checklist workflow in Intacct |
| AP Invoice Processing | 1) Vendor invoice received (email or AP automation inbox) 2) System auto-matches invoice to PO and receipt 3) Exceptions routed to AP clerk queue 4) Approval workflow routes by dollar threshold electronically | AP / Purchasing | Automated 3-way match; full electronic audit trail | System-enforced approval thresholds ($5K manager / $25K CFO); no manual override without documented reason |
| Job Costing | 1) Labor and material costs post directly to job in real time via time entry and PO receipt 2) PMs view live budget-vs-actual dashboard 3) Month-end job review requires no manual reconciliation | Projects | Real-time (same-day) job cost visibility | System-restricted job budget edits to PM/Controller roles only |
| Sales Order Creation | 1) Sales rep closes opportunity in Salesforce 2) Integration auto-creates sales order in Intacct 3) Order flows directly to Operations via Intacct notification | Order Entry (via Salesforce integration) | Same-day order creation; eliminates manual re-keying | System log of integration-created orders for audit |
| Milestone Billing | 1) PM updates job % complete directly in Intacct Projects 2) Billing schedule auto-generates draft invoice at milestone trigger 3) Controller reviews and releases | AR / Billing / Projects | Reduces billing lag from days to same-day | Draft-to-approved invoice workflow with Controller sign-off retained |
