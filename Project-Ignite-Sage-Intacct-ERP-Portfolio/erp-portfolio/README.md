# Project Ignite — Sage Intacct ERP Implementation Portfolio
### Meridian Fabrication Group (MFG)

This folder contains a fully populated, real-world-style example of an ERP implementation document portfolio, built around a fictional mid-size manufacturer, **Meridian Fabrication Group**, implementing **Sage Intacct** with the help of an implementation partner, **Elevate Consulting Partners**.

**Scenario summary:** $85M custom metal fabrication company, 2 legal entities, 3 sites (Dayton OH, Waco TX, Reno NV), 240 employees, migrating from QuickBooks Enterprise + spreadsheets to Sage Intacct. Project kicked off January 12, 2026; went live August 3, 2026; currently in stabilization as of September 1, 2026.

## Folder Structure
- **01-Project-Overview** — Charter, RACI, communication plan
- **02-Requirements-Gathering** — BRD, FRS, RTM
- **03-Current-vs-Future-State** — As-Is/To-Be processes, gap analysis, fit-gap analysis
- **04-Process-Mapping** — BPMN & swimlane outlines, workflow narratives
- **05-Configuration-Support** — Configuration workbook, chart of accounts, permissions matrix
- **06-Data-Migration-Validation** — Migration strategy, data mapping, migration templates, validation report
- **07-UAT** — UAT plan, test cases, defect log
- **08-Go-Live-Preparation** — Readiness checklist, cutover plan, user provisioning
- **09-Cutover** — Cutover execution log, opening balances report
- **10-Training-Adoption** — Training plan, quick reference guides, adoption metrics
- **11-Post-Go-Live-Support** — Hypercare log, stabilisation report, continuous improvement roadmap

All figures, names, and dates are illustrative, built to be internally consistent as a single coherent case study you can use as a reference, training example, or template starting point.
