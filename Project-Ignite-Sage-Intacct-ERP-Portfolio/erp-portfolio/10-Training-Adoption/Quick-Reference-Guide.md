# Quick Reference Guide (QRG) — AP Bill Entry & 3-Way Match

| Process | Steps | Screenshots (optional) | Tips | Errors |
|---|---|---|---|---|
| Enter a vendor bill | 1) Navigate to Accounts Payable > Bills > New 2) Select vendor, enter invoice number and date 3) Link to open PO if applicable 4) Enter line items and GL/dimension coding 5) Save and submit | See attached screen captures in printed binder, pages 4–6 | Always link to a PO when one exists — this triggers automatic 3-way match | If "No matching PO found" appears, confirm PO number and that it hasn't already been fully received/billed |
| Resolve a match exception | 1) Open AP > Exception Queue 2) Review flagged variance (price, quantity) 3) Contact Ops if quantity discrepancy; contact vendor if price discrepancy 4) Adjust or approve override with note | See page 7 | Overrides above $500 require Controller notification per policy | If exception won't clear after correction, verify PO line item status hasn't changed |
| Submit for approval | 1) Bill routes automatically based on dollar threshold 2) Approver receives email notification 3) Approver reviews in Approvals queue and approves/rejects | See page 8 | Check the Approvals dashboard daily to avoid payment run delays | If a bill is "stuck" in approval, confirm the correct approver role is assigned to that department |

# Quick Reference Guide (QRG) — Job Cost Entry (Project Managers)

| Process | Steps | Screenshots (optional) | Tips | Errors |
|---|---|---|---|---|
| Update job % complete | 1) Navigate to Projects > [Job Name] > Progress 2) Enter updated percent-complete 3) Save | See printed binder, page 12 | Update at least weekly to keep billing milestones accurate | If milestone invoice doesn't auto-generate, confirm the billing schedule is attached to the job |
| Review budget vs. actual | 1) Navigate to Projects > [Job Name] > Dashboard 2) Review cost type breakdown (Labor, Material, Overhead, Subcontract) | See page 13 | Red variance flags mean actual exceeds budget by more than 10% — review with Controller | If dashboard shows stale data, refresh browser; data updates in near-real-time, not instantly |
